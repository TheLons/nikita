# Никита против Дедлайна

Пиксельная игра-поздравление к 31-летию Никиты. После короткого пролога Никита сражается с Дедлайном, уклоняется от падающих с неба снарядов и собирает ноты для мощного «Финального аккорда». Победа открывает анимацию и поздравление.

## Как играть

- Перед боем выберите сложность: **Легко** сохраняет прежний темп (1–2 снаряда за атаку), **Сложно** даёт 2–4 одновременных снаряда и более частые залпы. Сложность можно сменить перед повтором боя.
- На телефоне: стрелки для движения; удерживайте «Огонь» для обычных выстрелов, нажмите «Ульта» после сбора трёх нот.
- На компьютере: стрелки или WASD для движения, пробел для обычной стрельбы, E для ульты.
- Обычные выстрелы снимают 1 HP, ульта — 6 HP. У Дедлайна 40 HP и три фазы; перед атакой он заряжается, затем на полу заранее появляются красные метки. Снаряды падают сверху в отмеченные точки. Пока метка светится, она не причиняет урона.
- После победы или поражения можно сразу начать заново. Звук выключается кнопкой в правом верхнем углу.

## Публикация на GitHub Pages

Workflow [`.github/workflows/pages.yml`](./.github/workflows/pages.yml) запускает тесты и публикует игру после каждого push в `main`. Сборка подготавливает только файлы сайта; дополнительных зависимостей у игры нет.

В **Settings → Pages → Build and deployment** источником должен быть выбран **GitHub Actions**. Состояние публикации видно на вкладке **Actions**. Адрес игры: `https://thelons.github.io/nikita/`.

Игра состоит только из статических файлов. В ней нет внешних зависимостей, сетевых запросов и чужих игровых изображений или музыки. Фон, босс, спрайт Никиты и экран победы лежат в `assets`. Исходные фотографии Никиты в комплект **не входят**.

## Как менять персонажа позже

Базовые позы Никиты находятся в [`assets/nikita-sprites.png`](./assets/nikita-sprites.png), а четыре кадра ходьбы — в [`assets/nikita-walk.png`](./assets/nikita-walk.png). Файл [`hero.js`](./hero.js) выбирает кадр, размер и направление. Персонажа можно заменить, не трогая правила боя в `game-core.js`. Текст поздравления находится в функции `showEnd` в `main.js`.

Площадка босса, часовой знак на полу, книжные стеллажи и видимая граница боя рисуются кодом в [`arena-stage.js`](./arena-stage.js). Герой и ноты ограничены той же областью в `game-core.js`, поэтому декорации остаются за пределами пути.

Четыре позы Дедлайна (покой, подготовка, атака и гибель) находятся в [`assets/deadline-sprites.png`](./assets/deadline-sprites.png). Они переключаются в `main.js` по состоянию боя.

## Проверка кода

При установленном Node.js запустите из этой папки:

```sh
node --test tests/*.test.js
```

Для локального просмотра через HTTP подойдёт любой статический сервер, например `python -m http.server 8000` и адрес `http://localhost:8000/`. Открытие `index.html` напрямую как файла может блокировать загрузку JavaScript-модулей в некоторых браузерах.
